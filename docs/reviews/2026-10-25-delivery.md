# Realism upgrade — delivery and validation

Delivery branch: `codex/realism-upgrade`, based on the reviewed GitHub main. Earlier local commits and the original main history are preserved. The delivery commit uses privacy-safe author metadata because GitHub rejected the earlier private-email history.

## Implemented

- Fictional 5.04 km Alpine Pass, plus selectable bundled Nordschleife geometry/DEM.
- Local 2K ambientCG asphalt/grass/ground color, normal and roughness maps; textured terrain and verges.
- Nearby instanced EZ-Tree branch/leaf geometry; lightweight distant foliage and distance culling.
- Physical sky/sun, nearby dynamic shadows, contact shadow, HDR environment reflections and daylight/golden-hour/overcast/wet-road settings.
- Detailed locally bundled Car Concept model, corrected baked wheel pose, spinning/steering wheels, cockpit/hood/chase cameras and brake emission.
- Fixed-step 240 Hz four-wheel suspension/tire/drivetrain simulation, actual barriers, TC/ABS, progressive controls, reverse and recovery.
- Waveguide engine worklet and synthesized tire, road, wind, shift and impact layers; audio suspends when paused/backgrounded.
- Local asset failure/retry behavior, responsive HUD and touch controls, credits and source/license manifests.

## Verified

- Fresh frozen dependency installation (`npm ci`).
- `npm test`: 19 passing tests covering physics, analog controller mapping, handbrake release, barriers, reverse, pause/reset, finite inputs, lap counting, actual GLB wheel-axis binding and bounded tree geometry.
- `npm run build`: production build passes. Three.js vendor chunk retains a size warning; app code is split separately.
- `npm run test:browser` against the production preview: both routes, golden-hour detailed trees, asset loading, acceleration, brake/recovery controls, all three cameras, pause/resume, audio worklet/mute, help and responsive layout. Zero page JavaScript errors and zero failed asset requests.
- `npm run test:route`: conservative headless full-route drive, 5,062.93 m traveled over a 5,042.89 m route, 353.05 simulated seconds, maximum lateral offset 2.89 m, zero off-road frames and zero rollovers.
- Fresh code review identified the imported front-wheel steering pose and lap-origin defects; both have failing-before/passing-after regression tests. Recovery input clearing and cockpit steering animation were also corrected.

## Decisions and limits

- The mountain route is original and fictional. No reusable scanned map with suitable verified access/license was found. The authentic circuit option remains approximate scenery around real road data.
- Car dimensions and a rear-biased sports-car tune were aligned with the model and tested solver. These values are not manufacturer-calibrated. The standalone unsteered brake test reaches the grass verge and uses a three-second braking interval; it is not an asphalt stopping-distance certification.
- Lower quality uses transparent glass; High uses refraction. Nearby 3D trees switch to lighter foliage at distance. These are rendering-budget/fidelity tradeoffs.
- EZ-Tree leaf images were extracted from its npm 1.1.0 artifact and matched exactly to the upstream Git LFS SHA-256 OIDs after direct LFS access failed. No LFS pointer placeholders are shipped. Generator and texture attribution is retained.
- Audio remains synthesis, not the previously researched Sonniss recordings, whose access/license were not independently established here.
- Cloud Chromium used software WebGL and rendered slowly. No desktop/mobile hardware frame-rate, physical gamepad, high-speed complete lap or engineering-simulator accuracy claim is made.
- Source pushes do not verify a deployment. No Vercel connector/credentials are exposed to this session, and requests to the existing live URL are denied by network policy. The live deployment remains unverified.
- Reusable cloud install/start instructions are saved as an environment configuration draft, separate from Vercel. Review/save and publish that environment configuration in environment settings to retain the setup.
